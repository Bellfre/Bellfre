# Bellfre Tools

The **tools** directory contains developer utilities used to support the Bellfre project. These scripts are intended to assist with research, data collection, validation, testing, and other project maintenance tasks. They are not part of the Bellfre SDK or runtime.

## Current Tools

### `census.py`

The first Bellfre utility.

Reads and displays the **Bellfre Agent Census (BAC)** stored in `data/census/`. This tool serves as the starting point for cataloging publicly known AI agents and validating the census data as the Bellfre ecosystem grows.

## Future Tools

As Bellfre evolves, this directory may include utilities for:

* Census validation
* Agent Card retrieval
* Registry synchronization
* BUI generation
* BAT generation
* Data import/export
* Health verification
* Integrity and signature validation

These tools support Bellfre development and research and may later evolve into administrative or command-line utilities for managing the Bellfre Registry.
