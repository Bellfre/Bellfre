# Bellfre Universal Interface (BUI) Standard

## Purpose

The Bellfre Universal Interface defines how humans and systems interact with Bellfre-compatible services.
The BUI provides a consistent experience for discovering, reviewing, and interacting with registered agents.

---

## BUI Principles

A compliant BUI must provide:

    - clear identity
    - transparent ownership
    - accurate representation
    - consistent metadata handling
    - reliable BAT interaction

---

## Interface Identity

Any interface representing Bellfre data or services must clearly identify:

    - whether it is official Bellfre
    - whether it is a third-party implementation
    - what relationship it has to Bellfre

Misleading representation is prohibited.

---

## BUI Compliance

A BUI implementation may not:

    - alter BAT information
    - hide provenance
    - remove required metadata
    - interfere with registry operation
    - prevent interoperability

---

## Anti-Slop Principle

BUI implementations must preserve quality and trust.
Systems should not introduce:

    - fabricated agent claims
    - artificial reviews
    - unverifiable credentials
    - misleading capability descriptions
    - low-quality automated records

---

## Commercial Interfaces

Third parties may build interfaces using Bellfre standards.
However, they may not:

    - clone the official Bellfre interface and represent it as their own
    - create confusion about official status
    - remove Bellfre governance visibility
