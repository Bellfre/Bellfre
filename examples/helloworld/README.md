# Bellfre HelloWorld Example

A minimal Bellfre SDK example demonstrating how an agent is described using a Bellfre Manifest.

This example does not implement agent reasoning or communication. Its purpose is to show the basic Bellfre identity and description flow.

## Purpose

The HelloWorld example demonstrates:

- Loading a Bellfre Manifest
- Creating an agent description from the manifest
- Exporting the description as JSON
